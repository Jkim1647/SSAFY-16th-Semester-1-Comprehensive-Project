## 2. 비기능적 요구사항

| 번호 | 분류 | 요구사항명 | 요구사항 상세 | 대응 |
| --- | --- | --- | --- | --- |
| NF101 | UX | 사용 편의성 | 사전 지식 없이 쓸 수 있어야 함 | 지도 중심 2단 레이아웃, 메인 빠른 검색, 빈 화면·오류 시 안내 문구, 토스트 피드백 |
| NF102 | UI | 가용성 | 어떤 기기로든 이용 가능 | Bootstrap 반응형 — 모바일(≤991px)에서 지도 위·목록 아래, 가로 스크롤 없음(375px 확인) |
| NF103 | 효율성 | 응답성 | 조회 결과를 빠르게 응답 | SDK 동적 로딩, 충전소·날씨·경로 응답 캐시, 입력 디바운스, 이미지 lazy loading |
| NF104 | 효율성 | 정확성 | 신뢰성 있는 공공데이터 사용 | 관광공사·환경공단 공공데이터 사용, 대한민국 범위 밖 좌표 제외, 2026 법정동 코드 변경(광주·전남→12) 반영 |
| NF105 | 보안 | 입력·출력 안전성 | XSS·권한 우회 방지 | 모든 동적 HTML `escapeHtml`, 본문 `textContent`, 작성자 권한 재확인, 비밀번호 SHA-256 해시, 로그인 리다이렉트 화이트리스트, API 키 `.env` 분리 |
| NF106 | 접근성 | 키보드·스크린리더 | 마우스 없이도 핵심 기능 사용 | 폼 라벨·`aria-live`·`aria-current`, 계획 순서 `Alt+↑/↓`, 포커스 표시 |
| NF107 | 법·정책 | 저작권 | 이미지 이용 조건 준수 | 공공누리 1·3유형 이미지만 표시하고 출처 표기 |

## 3. 데이터 저장 구조 (localStorage)

| 키 | 내용 |
| --- | --- |
| `enjoytrip.users` | `{ id, passwordHash, name, email, role, createdAt }` |
| `enjoytrip.session` | 로그인한 아이디 |
| `enjoytrip.plans` | `{ id, userId, title, startDate, rangeKm, efficiency, pricePerKwh, stops[{ spotId, title, address, x, y, time, cost, category, memo }] }` |
| `enjoytrip.draftPlan` | 작성 중인 계획 (저장 전 초안) |
| `enjoytrip.hotplaces` | `{ id, userId, title, category, visitDate, address, x, y, photo(dataURL), verified, description }` |
| `enjoytrip.posts` | `{ id, type(notice/free), title, content, writerId, writerName, views, createdAt, updatedAt }` |

## 4. 외부 API

| API | 용도 | 키 |
| --- | --- | --- |
| 한국관광공사 국문 관광정보 서비스_GW (KorService2) | 관광지 목록·검색·상세·사진, 법정동 코드 | `DATA_GO_KR_API_KEY` |
| 한국환경공단 전기자동차 충전소 정보 | 충전소·충전기 상태 | `EV_API_KEY` (없으면 `DATA_GO_KR_API_KEY`, 별도 활용 신청) |
| Kakao Maps JavaScript SDK | 지도, 마커, 주소↔좌표 | `KAKAO_MAP_KEY` |
| 카카오모빌리티 길찾기 | 실제 도로 경로 (선택) | `KAKAO_REST_KEY` |
| Open-Meteo | 날씨 예보, 일출·일몰 | 불필요 |
