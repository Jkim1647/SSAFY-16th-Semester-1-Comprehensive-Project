# 관통 프로젝트 폴더 안내

2차 이후 관통 프로젝트를 이 저장소 안에서 차수별로 보관합니다.

## 폴더 이름

```text
차수-프로젝트명
```

예시:

```text
02-gwangju-quest-chatbot
03-enjoytrip-database
04-enjoytrip-spring
```

각 폴더는 다른 차수 프로젝트에 의존하지 않고 실행할 수 있는 독립된 제출 단위로 관리합니다. 최소한 다음 자료를 포함합니다.

- 구현 소스 코드
- 실행 방법과 주요 기능을 기록한 `README.md`
- 실제 실행 화면
- 과제에서 요구한 고찰·평가 문서

API 키와 개인 인증 정보, `.env`, 가상환경, 빌드 결과와 로컬 데이터베이스는 포함하지 않습니다.
