# 개선된 요구사항 목록 — EnjoyTrip EV (Web Backend PJT)

명세서(5회차)의 요구사항 예시를 바탕으로, 4회차까지 이어 온 **전기차 여행** 컨셉에 맞게 고치고 늘렸다.
굵게 표시한 항목이 이번 회차에 새로 추가하거나 크게 바꾼 것이다.

## 기능적 요구사항

| F102 | 여행 | 관광지·숙박·음식점 조회 | 콘텐츠 유형(12·32·39) 필터 + 이름 검색 + 페이징, 지도 마커 | 필수 | `/attraction?type=` |
| F103 | 여행 | 문화시설·공연·여행코스·쇼핑 조회 | 콘텐츠 유형(14·15·25·38) 필터, **레포츠(28)** 추가 | 필수 | `/attraction?type=` |
| F104 | 여행 | 여행 계획·경로 | 관광지를 검색해 담고 드래그앤드롭으로 순서 변경, 일정·경비·메모 저장. **방문 순서 최적화(Held-Karp / 2-opt)**, **충전소 경유 경로(Dijkstra)** 계산 | 추가 | `/plan` |
| F105 | 여행 | 회원 hotplace 등록 | 사진(검증된 이미지만)·지도 위치·방문일·장소 유형·설명 등록, 지도에 표시 | 추가 | `/hotplace` |
| F106 | 여행 | 관광지 뉴스 크롤링 | 관리자가 검색어로 Google News RSS 를 수집해 DB 에 저장(중복 제외), 누구나 조회 | 심화 | `/news` |

| F108 | 회원 | 로그인 관리 | 로그인/로그아웃, 비밀번호 찾기(**15분 1회용 재설정 링크**, 계정 존재 여부 비노출, 요청 횟수 제한) | 필수 | `/member` |
| F109 | 커뮤니티 | 통합 게시판 공지 | 통합 게시판의 공지 유형. 관리자만 등록·수정·삭제 및 고정 여부·순서·한국 시간 노출 기간 설정, 누구나 공개 공지 조회 | 심화 | `/board?type=notice` |
| F110 | 커뮤니티 | 통합 게시판 | 공개 글은 누구나 조회. 로그인 작성, 작성자·관리자 수정/삭제. 공지와 목록 통합, 검색·페이징·세션별 조회수 | 심화 | `/board?type=free` |
| F111 | 기타 | 관광지 날씨 | 관광지 상세에 7일 예보 (Open-Meteo) | 추가 | 관광지 상세 |
| F112 | 기타 | 관광지 사진 | 관광공사 대표 사진, 회원 핫플 사진 | 추가 | 관광지 상세 / 핫플 |
| F113 | 기타 | 일출·일몰 | 관광지 상세 예보에 일출·일몰 시각 | 추가 | 관광지 상세 |
| F114 | 기타 | 전기차 충전소 | 환경부 충전소 8,072곳(광주·전남) 지도·근처 검색·**시간대별 예약 현황** | 추가 | `/ev` |
| **F115** | **EV** | **충전기 시간대 예약** | 충전소×1시간 슬롯을 좌석처럼 예약·취소. 동시에 눌러도 충전기 수를 넘겨 확정되지 않음(트랜잭션 + 행 잠금) | **추가(팀 고유)** | `/ev?action=station` |
| **F116** | **EV** | **예약 몰림 시뮬레이션** | "연휴 전날 저녁 7시" 이야기로 시작해, 가상 차량 N대가 대기열(메모리 큐 / Kafka)에 줄을 서서 실제 DB 예약을 시도. 배터리 격자·좌석 배치도·로그로 실시간 표시, 잠금 예약 vs 잠금 없음 오버부킹 비교 | **심화(팀 고유)** | `/sim` |

## 비기능적 요구사항

| 번호 | 분류 | 요구사항명 | 상세 |
|---|---|---|---|
| NF101 | UX | 사전 지식 없이 사용 | 3회차 프론트 디자인(지도 중심 앱형)을 JSP 로 옮김, 이야기형 인트로로 서비스 목적 전달 |
| NF102 | UI | 어떤 기기에서나 | Bootstrap 반응형, 지도+패널 레이아웃은 모바일에서 세로 배치 |
| NF103 | 효율성 | 빠른 응답 | 목록은 DB 페이징(LIMIT/OFFSET), 시뮬레이션 상태는 250ms 폴링, 충전소 근처 검색은 위경도 사각형으로 먼저 거름 |
| NF104 | 정확성 | 신뢰할 수 있는 데이터 | 관광공사·환경부 공공데이터, 예약은 DB 제약·잠금으로 정원 초과 0 |
| **NF105** | **동시성** | **예약 정합성** | 32개 스레드 동시 예약 테스트에서 확정 수 = 충전기 수 (`EvServiceConcurrencyTest`) |
| **NF106** | **보안** | **기본 보안** | 비밀번호 PBKDF2+salt+pepper(4회차 모듈), 세션 고정 방지, CSRF 토큰, 출력 이스케이프(XSS), PreparedStatement(SQL 인젝션), 업로드 이미지 검증·경로 조작 차단, JSP 는 WEB-INF 아래 |
| **NF107** | **이식성** | **팀원 PC 에서 바로 실행** | 지도는 키 없는 Leaflet+OSM, Kafka 없으면 메모리 큐로 대체, DB·테이블·기준 데이터는 첫 실행 때 자동 생성 |
| NF108 | 정합성 | 게시판 반응 정합성 | 복합 PK·명시적 등록/해제·부모 글 잠금·트랜잭션으로 중복 및 동시 삭제 검증 |
| NF109 | 개인정보 | 개인 활동 접근 제한 | 회원 식별은 세션 기준, 북마크 등 개인 목록은 본인만 조회 |
| NF110 | 운영 | 게시판 추적 | 요청 ID·처리 시간 로그, 관리자 조치와 사유 기록 |
| NF111 | UX | 반응 오류 복구 | 저장 중 버튼 잠금, 서버 확인 후 상태 반영, 실패 후 재시도·복구 |
