# 예약 정확도 보완

LOCKED 예약은 회원 행을 먼저 잠그고 슬롯 행을 잠근다. 같은 회원이 서로 다른
충전소에 동시에 요청해도 먼저 확정한 예약을 다음 요청이 확인하므로 동일 시간
중복 예약을 거절한다. 예약 취소도 같은 회원 잠금을 사용한다.

충전기 번호는 예약 건수가 아니라 해당 슬롯의 확정 예약에서 사용하지 않는
가장 작은 번호를 배정한다. 취소된 번호를 재사용하므로 취소 후 재예약에서도
다른 확정 예약의 충전기 번호와 겹치지 않는다.

중복 조회와 빈 번호 조회는 회원·슬롯 잠금을 획득한 뒤 트랜잭션의 첫 일반
조회로 실행한다. 취소 조회는 예약 행만 잠그며 충전소 행 전체를 잠그지 않는다.
회원별 직렬화는 같은 회원의 다른 시간 예약에도 적용되는 단순한 방식이다.

비교 실험용 NAIVE 경로는 기존의 정원 초과 재현 동작을 유지한다.
이 변경은 기존에 잘못 배정된 예약 번호를 자동으로 재작성하지 않는다.

검증:

    ./mvnw -Dtest=EvReservationIntegrityTest,EvServiceConcurrencyTest test

- 만석 상태에서 취소 후 빈 충전기 번호 재사용과 정원 복구
- 동일 회원이 서로 다른 충전소에 보내는 동시 요청 16건 중 1건만 확정
- 취소 후 같은 회원의 다른 충전소 재예약
- 취소와 다른 회원의 신규 예약 동시 실행
- 기존 LOCKED 정원 준수 및 NAIVE 정원 초과 비교

실제 MySQL을 사용하며, 정확도 테스트의 임시 회원·충전소·예약은 종료 시 제거한다.
DB가 없으면 테스트가 건너뛰어지므로 skipped 수를 함께 확인해야 한다.
