# 광주 지역별 여행 선택 가이드

이 문서는 사용자가 특정 구나 출발 지역을 말했을 때 후보를 빠르게 좁히기 위한 검색용 가이드다. 장소 상세 설명은 `gwangju_attractions.md`를 참고한다.

## 동구 여행

동구는 광주가 처음인 여행자, 문화와 카페를 함께 원하는 사람, 2~4시간의 짧은 도심 여행에 우선 추천하기 좋다.

- 문화 중심: 국립아시아문화전당
- 역사와 도시 의미: 5·18민주광장
- 카페와 대화: 동명동
- 식사와 도심 구경: 충장로
- 예술 골목 관찰: 예술의 거리

추천 연결: ACC → 5·18민주광장 → 동명동 또는 충장로. 모든 곳을 넣기보다 사용자의 취향에 맞춰 2~3곳을 고른다. 비 오는 날에는 ACC 비중을 높이고 야외 골목 체류를 줄인다.

## 남구 여행

남구의 양림동 생활권은 역사문화, 레트로 사진, 골목 산책을 좋아하는 친구나 연인에게 잘 맞는다.

- 이야기 있는 산책: 양림동 역사문화마을
- 공예와 생활 골목: 펭귄마을공예거리
- 산책과 시야가 트인 공간: 사직공원 주변

추천 연결: 양림동의 관심 지점 1~2곳 → 펭귄마을 → 체력이 남으면 사직공원 주변. 부모님이나 걷기 어려운 동행자와 함께라면 범위를 줄이고 휴식시간을 먼저 넣는다.

## 북구 여행

북구는 미술·박물관과 공원을 조합하거나 광주호 방향 자연 여행으로 확장할 때 적합하다.

- 현대미술: 광주비엔날레 전시관 주변
- 역사문화: 국립광주박물관
- 공원 휴식: 중외공원
- 근교 자연: 광주호 호수생태원 주변

추천 연결: 국립광주박물관 → 중외공원 → 현재 전시가 있다면 비엔날레 전시관 또는 광주시립미술관. 광주호는 도심 코스에 억지로 붙이지 말고 이동수단과 시간을 확인한 뒤 별도 자연 코스로 잡는다.

## 서구 여행

서구는 상무지구를 기반으로 식사와 실내 휴식을 확보하고 5·18기념공원 또는 광주천 산책을 더하는 방식이 좋다.

- 역사와 산책: 5·18기념공원
- 식사·카페·저녁 일정: 상무지구
- 가벼운 야외 산책: 가까운 광주천 구간

걷기 싫어하는 사람, 출장이나 일정 사이 시간이 남은 사람에게는 한 생활권 안에서 장소 수를 줄이는 방향을 추천한다.

## 광산구 여행

광산구는 광주송정역 도착·출발 시간과 연결해 계획하는 경우가 많다.

- 여행 관문: 광주송정역
- 짧은 시장·먹거리 탐색: 1913송정역시장
- 도시철도 이동: 광주송정역에서 문화전당역 방향 원도심 연결 가능

열차까지 1~2시간밖에 없다면 역에서 멀리 이동하지 않는다. 반나절이면 짐과 숙소 위치를 확인한 뒤 원도심 또는 상무지구로 이동하는 코스를 제안한다.

## 자연 중심 지역 선택

- 산과 탐방: 무등산국립공원
- 호수와 생태 산책: 광주호 호수생태원 주변
- 도심 공원: 중외공원, 5·18기념공원
- 짧은 일상 산책: 위치에 맞는 광주천 구간

자연 여행에서는 시간보다 체력, 날씨, 일몰, 탐방로 상태가 더 중요할 수 있다. 실시간 조건은 공식 정보를 확인한다.

## 사용자의 자연어와 지역 매칭

- "광주 처음" → 동구 원도심을 기본 후보로 제안
- "광주송정역에서 시작" → 1913송정역시장 또는 도시철도 1호선 연계
- "양림동 근처" → 역사문화마을, 펭귄마을, 사직공원 주변
- "비엔날레 보고 싶어" → 북구 중외공원 문화예술권
- "상무에서 뭐 하지" → 상무지구와 5·18기념공원 조합
- "자연 위주" → 무등산 또는 광주호, 시간과 이동수단 추가 확인
